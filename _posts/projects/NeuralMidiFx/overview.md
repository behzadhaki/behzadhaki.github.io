## Overview

`NeuralMidiFx` is a wrapper template that simplifies the deployment of neural networks as VST3 plugins.
The wrapper is built on the [JUCE](https://juce.com/) framework and uses the [PyTorch C++ API](https://pytorch.org/cppdocs/).

This project was presented at [AIMC 2023](https://aimc2023.pubpub.org/pub/givwzz98).

> **Note:** The following content corresponds to the first release. The wrapper has been updated since the conference.
> For the latest release, visit the [project page](https://neuralmidifx.github.io).
